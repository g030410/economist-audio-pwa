# Weekly Audio

A small, installable PWA that provides a mobile-friendly home for the existing Economist weekly audio player.

## Publish with GitHub Pages

1. Push the files to the repository's default branch.
2. In repository Settings → Pages, choose Deploy from a branch.
3. Choose the default branch and `/ (root)`, then save.
4. Open the Pages URL on your phone. On iOS use Safari Share → Add to Home Screen; on Android use Chrome Install app.

The app caches its own interface only. The player and audio remain hosted by the linked third-party site and require internet access.
